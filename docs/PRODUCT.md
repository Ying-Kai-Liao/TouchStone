# PlanLM (working title) — Product Definition

## One sentence
A daily companion that helps users see today’s reality and gently acknowledge what they actually touched.

## What it is
- A calm place to check today's fixed events (Stones)
- A gentle way to acknowledge work via “touch”
- An optional Focus Mode container to help users stay for ~1 hour
- A tool that feels safe to open even on bad days

## What it is NOT
- Not a task planner
- Not a schedule optimizer
- Not a productivity scoreboard
- Not a system that assigns tasks into time slots
- Not a tool that shames users with overdue, streaks, or completion %

## Core problem we solve
- "Hard start of day" and calendar guilt
- Users need permission to engage and permission to stop
- Users need a lightweight ritual that doesn’t turn into pressure

## Target daily experience
Opening the app should feel like:
1) "Here’s today’s reality."
2) "Do I want to engage a little?"
3) "I touched something meaningful (acknowledged)."
4) "I can stay (Focus Mode) or leave safely."

## Success criteria (v0.1)
- User opens the app without feeling pressure
- User can log a touch in < 2 seconds
- Focus Mode feels optional and safe to exit anytime
