## Core Principles (Summary)

From our documentation, these are the non-negotiable principles:

1. **The app does the planning** — User just executes
2. **"Enough" is explicit** — A real number, not a feeling
3. **Bad days are built in** — Redistribute, don't guilt
4. **Rest is a valid state** — Not a failure mode
5. **Every UX decision must reduce mental load** — If it adds load, find another way
